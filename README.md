# MARV V2 flight controller

Flight controller for rockets/drones that stacks on a MicoAir AM32 4-in-1 ESC (2-6S, no BEC): RP2354B MCU, ICM-45686 IMU, BMP581 barometer, ADXL375 high-g, QSPI flash-or-PSRAM socket + microSD logging, 8 PWM outputs (4 to the ESC, 4 servo), ESC current sense and KISS telemetry input, GPS / ELRS / magnetometer pad rows, WS2812C RGB status LED, buzzer driver, USB-C. Raw pack (6-25.2 V) comes in on the ESC pad row and an on-board AP63205 buck makes 5 V; USB is the fallback source through a TPS2121 priority mux. Solder pads for every bus, 2.54 mm through-hole for leftover IO only. Firmware and PCB layout are not done; the PCB is empty.

## File map

- [DESIGN_SPEC.md](DESIGN_SPEC.md) — power, rails, sheets, GPIO map, decisions.
- [LIBRARIES.md](LIBRARIES.md) — nonstandard parts and layout rules.
- `*.kicad_sch` — 8 hierarchical sheets (root + power_sources, power_3v3, power_periph, mcu, sensors, storage, actuators), all power/board sheets generated by `tools/build_power.py`.
- `tools/` — `build_power.py` (generator), `check_power_netlist.py`, `run_power_checks.py`, `audit_footprints.py` (footprint / 3D-model readiness).
- `tools/3d/` — FreeCAD scripts that generate the simplified STEP models, plus `bbox.py` (bounding box of a STEP); see [tools/3d/README.md](tools/3d/README.md).
- `MARV_Packages.pretty/` — project-local footprints: eight official KiCad footprints vendored so they can carry project-local 3D models, plus the project-authored solder pad rows (`PadRow_1x02/03/04/08_P2.00mm`) and the grommet mounting hole (`MountingHole_4.0mm_Grommet`), which carry no 3D model by design.
- `MARV_Packages.3dshapes/` — the STEP models those footprints reference, with [provenance, licences and SHA256 sums](MARV_Packages.3dshapes/PROVENANCE.md).
- `simulations/` — ngspice decks and [results](simulations/README.md).
- `reports/` — ERC report, netlist export, schematic PDF.
- [power_bom.csv](power_bom.csv) — preliminary BOM, not purchase-ready.
- `backups/` — pre-revision schematic and DESIGN_SPEC snapshots.

`tools/build_power.py` overwrites generated sheets: edit the generator, not the sheets.

## Reproduce checks

```sh
kicad-cli sch erc --severity-all --exit-code-violations -o reports/power-erc.rpt MARV-V2.kicad_sch
kicad-cli sch export netlist MARV-V2.kicad_sch --format kicadxml -o reports/power-netlist.xml
python3 tools/check_power_netlist.py reports/power-netlist.xml
python3 tools/run_power_checks.py
kicad-cli sch export pdf MARV-V2.kicad_sch -o reports/MARV-V2-power.pdf
python3 tools/audit_footprints.py reports/power-netlist.xml
```

Python tools use the standard library; ngspice and kicad-cli must be installed.
